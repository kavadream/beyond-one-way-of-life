# 来源与阅读边界

本书以原创现代叙事为主体。以下资料用于定位古典篇章、核查故事归属与提醒文本解释的限度。来源标记 S1 至 S9 对应正文中的方括号编号，编号不是研究结论的权重。网页查阅日期：2026年11月3日。

古典正文与现代解读须分开阅读。本书没有搬录现代中文译文，没有把现代人物附会成古代人物的真实经历，也不把哲学寓言用作心理疗效或社会规律的实验证据。书中全部现代故事均为原创虚构。古典人物在寓言中的言行不等于可直接验证的生平事实。

## S1　《庄子》内篇《逍遥游》第一

查阅范围：开篇关于飞行与所凭借条件的段落，不同生命的时间尺度，宋荣子段落。用于第二、六、八章；第三章关于用途的整体背景亦与本篇末尾有关。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/逍遙遊)

[香港教育局《逍遥游》节录及注释](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS4_05.pdf)

教育局材料中核读了末尾惠子与庄子谈大瓠、大树的原文，作为用途主题的交叉参照；其现代赏析、注释和现代著作引文未移录到本书。本书不因所列教学资料采用某种作者生平叙述，就将其全部当成已经确证的史实。

现代延伸：本书讨论年龄压力、评价的范围及行动条件。原篇不讨论现代招聘、照护排班或生育决策，不应倒推为对这些具体事项的直接建议。

## S2　《庄子》内篇《人间世》第四

查阅范围：匠石与栎社树的寓言及篇末关于用途的议论。用于第三、十三章。“无用之用”四字以简体写法出现，用于指示这一古典讨论，不是现代译者的句子。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/人間世)

现代延伸：本书追问用途是谁设定、是否所有闲暇都要证明收益。不将保身处境直接等同于现代劳动环境，也不以古代政治处境要求现代人忍受伤害或放弃必要救济。

## S3　《庄子》外篇《山木》第二十

查阅范围：篇首树木与雁的情节及随后的回答。用于第三章，限制“无用便一定安全”这一过度简单的推断。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/山木)

现代延伸：店铺经营中的取舍由本书虚构人物承担，不是古典故事保证的一种经营方法。本书没有把外篇直接等同于庄周本人留下的言论记录。

## S4　《庄子》内篇《齐物论》第二

查阅范围：彼此与是非的相关论述，名称与判断的讨论。用于第四、七、十四章。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/齊物論)

现代延伸：本书据此留意身份标签、争论前提及解释的未定性。这是一条当代阅读路径，不声称概括了全篇学术解释，更不从中推出事实不存在、责任不必区分或任何行为都无可批评。

## S5　《庄子》外篇《秋水》第十七

查阅范围：河伯与北海若的对话，关于尺度、器具与本领适用情境的段落。用于第一、五章。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/秋水)

现代延伸：本书讨论比较所用的尺度以及转行时可迁移和不可直接迁移的经验。该篇不是现代职业研究，不提供转行成功率或对具体个人的能力判断。

## S6　《庄子》内篇《养生主》第三

查阅范围：庖丁寓言，特别留意熟练之后遇见复杂情形仍减缓动作的部分。用于第九章。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/養生主)

现代延伸：本书关注熟练中的观察、谨慎和停止。没有把该寓言等同于“心流”、神经机制、操作规范或医疗健康建议。维修故事只说明人物处境，不是电器维修教程。

## S7　《庄子》外篇《至乐》第十八

查阅范围：庄子妻死故事、海鸟故事。分别用于第十、十二章。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/至樂)

现代延伸：本书不把古典人物的情感变化规定为丧亲者应遵循的时间表；关于照顾与善意的讨论，也不将人的需求视为固定不变。本书不对任何真实个人的悲伤作诊断。

## S8　文本形成与解释的学术背景

Chad Hansen，〈Zhuangzi〉，Stanford Encyclopedia of Philosophy。网页列出初刊日期2014年12月17日，实质修订日期2024年3月24日。核读其文本形成与解释分歧部分。

[全文与书目](https://plato.stanford.edu/entries/zhuangzi/)

Esther Klein，〈Were there “Inner Chapters” in the Warring States? A New Examination of Evidence about the Zhuangzi〉，T’oung Pao，96卷4–5期，2010年，299–369页。DOI：10.1163/156853210X546509。

[作者研究成果记录与摘要](https://researchportalplus.anu.edu.au/en/publications/were-there-inner-chapters-in-the-warring-states-a-new-examination/)

[论文 DOI](https://doi.org/10.1163/156853210X546509)

使用范围：本书仅根据已核读的百科正文与作者论文摘要，提醒读者不要把今本全部篇章的作者归属视为无争议事实。Klein论文此处核读的是公开摘要及书目信息，未宣称读过其全部71页，也未借摘要复述具体论证。前言、第十一、十四章的相关表述限于这一层次。不同学术解释并不因此失去优劣之别。

## S9　《庄子》内篇《应帝王》第七

查阅范围：篇末浑沌寓言。用于第十二章。

[古典正文电子文本](https://zh.wikisource.org/wiki/莊子/應帝王)

现代延伸：由善意干预的风险引出尊重他人选择，不据此否定一切教育、必要照护或协商。是否接受一种帮助，仍需考虑当事人的能力、处境、权利与具体责任。

## 关于版本与继续阅读

本书所列维基文库页面是便于定位篇章的电子文本，存在异体字、校记和编辑更新，不是本书独立完成的校勘定本。香港教育局选段用于相关部分的交叉阅读。正文没有铺陈有争议的字词训诂，也没有把未实际逐页查阅的纸本版本列作已核读来源。

需要深入研读时，可以比较不同古注、现代校注与学术解释；进行正式学术论证或对外定稿前，应按选定底本进一步校读。读者发现篇章归属、字词或解释范围问题，可注明所在章节和对应来源提出勘误。

来源只保留书目信息、链接与必要的短述。未附第三方书籍、论文或教学材料全文，也未复制其现代翻译与注释。古典公共领域材料及依法可自由使用的思想不纳入本书的专有权利主张。
